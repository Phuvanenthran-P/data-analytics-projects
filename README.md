# 📊 Data Analytics Projects

Python data analysis and visualization projects using Pandas, Matplotlib, Seaborn and Plotly.

## Projects

| Project | Description | Tools |
|---|---|---|
| [Stock Market Analysis](./stock-market-analysis) | Intraday stock data with 50-period SMA/EMA trend analysis and crossover signals | Python, Pandas, yfinance, Plotly, Matplotlib |
| [Phone Usage Analysis](./phone-usage-analysis) | Exploratory analysis of Indian mobile usage: screen time, data usage, calls, app installs | Python, Pandas, Seaborn, Plotly |

## Skills Demonstrated

- Data collection from APIs and CSV files
- Data cleaning and exploratory data analysis (EDA)
- Time-series trend analysis (SMA, EMA)
- Correlation analysis and interactive visualization
- Jupyter and Google Colab workflows

## Run Locally

```bash
git clone https://github.com/Phuvanenthran-P/data-analytics-projects.git
cd data-analytics-projects
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook
```
