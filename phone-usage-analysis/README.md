# 📱 Phone Usage Analysis (India)

Exploratory data analysis of mobile phone usage patterns: screen time, data usage, call duration and app installations.

## What It Does

- Cleans and explores the dataset (EDA)
- Visualizes usage patterns across metrics
- Builds a correlation heatmap to find related metrics
- Creates interactive scatter and pie charts with Plotly

## Dataset

`phone_usage_india.csv`

## Tech Stack

Python · Pandas · Matplotlib · Seaborn · Plotly · Google Colab

## Run It

Open `Phone_Usage_Analysis.ipynb` in Google Colab or Jupyter and run all cells. Keep the CSV in the same folder as the notebook.
